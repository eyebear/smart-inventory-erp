# Inventory Sync and Waste Reduction System

This project is a full-stack ERP-style inventory management system designed for an Asian supermarket business environment.

The system focuses on inventory synchronization, expiry tracking, waste reduction, supplier integration, and store operation dashboards.

## Business Context

Asian supermarkets handle many fresh, imported, and expiry-sensitive products. This system simulates an internal tool that helps store managers and administrators monitor inventory, reduce waste, and integrate modern web applications with legacy systems.

## Tech Stack

- React
- TypeScript
- Next.js
- Node.js
- MySQL
- PHP
- GitHub Actions

## Main Components

| Component | Purpose |
|---|---|
| frontend | React/Next.js dashboard |
| backend | Node.js REST API |
| legacy-php | Simulated legacy PHP service |
| database | SQL schema and seed data |
| docs | SRS, API documentation, workflow notes |

## Planned Features

- Multi-store inventory tracking
- Product batch and expiry tracking
- Expiring product alerts
- Waste analytics
- Supplier data integration
- Legacy PHP service integration
- Role-based access control
- CI with GitHub Actions
